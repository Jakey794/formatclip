# Changelog

All notable changes to FormatClip are documented here. The project follows
[Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-08-15

### Added

- Branded extension icon set and toolbar-to-side-panel behavior
- Frontend unit and accessibility-oriented rendering tests
- Production bundle and source-map budgets
- CodeQL, Dependabot, dependency auditing, and public security guidance
- Contribution templates and public project documentation

### Changed

- Standardized the default branch on `main`
- Upgraded the supported extension toolchain
- Improved narrow-width behavior, focus visibility, live announcements, and
  reduced-motion support
- Bounded backend request sizes and made CORS configuration effective
- Declared FormatClip as a stable local-first 1.0 release

[1.0.0]: https://github.com/Jakey794/formatclip/releases/tag/v1.0.0
